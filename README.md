## 📌 Sobre Este Repositório

Este repositório contém a versão digital e interativa do meu currículo profissional, disponível tanto em formato **Web responsivo (HTML5/CSS3)** quanto em documento **PDF oficial** pronto para impressão ou envio.

O design foi concebido com tipografia moderna (**Inter**), paleta de cores sóbria e elegante, estruturado no padrão internacional de **uma página A4 (Single-page Resume)**, proporcionando alta densidade de informação com excelente legibilidade tanto na tela quanto impresso.

## 🌐 Publicação no GitHub Pages (Opcional)

Para disponibilizar o currículo online em uma URL própria (ex: `https://otoniel-sys.github.io/curriculo/`):

1. Acesse o repositório no GitHub.
2. Vá em **Settings** > **Pages**.
3. Em **Branch**, selecione `main` (ou `master`) e a pasta `/ (root)`.
4. Clique em **Save**. Em instantes o currículo estará online com links ativos e botão de download.
